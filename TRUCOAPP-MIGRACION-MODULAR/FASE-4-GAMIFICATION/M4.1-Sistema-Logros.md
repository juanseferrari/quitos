# 🏆 M4.1 - SISTEMA DE LOGROS AVANZADOS
## Arquitectura: Backend Go + Frontend React

## 📋 OBJETIVO
Implementar un sistema completo de logros y achievements que gamifique la experiencia de juego, motivando engagement a largo plazo mediante un backend en Go para cálculo de logros y un frontend React para visualización premium.

---

## 🎯 ALCANCE

### ✅ Lo que INCLUYE
- **50+ Achievements**: Sistema completo según UX flow original
- **5 Categorías Principales**: Victorias, Rachas, Dominancia, Equipos, Especiales
- **Estructura Progresiva**: (1, 10, 25, 50, 100, 250, 500) por categoría
- **Logros Especiales**: Jugar de madrugada, días específicos, etc.
- **Progress Tracking**: "████████░░ 127/250" visual system
- **Categoría Freemium**: 5 logros básicos gratis, 50+ premium
- **Backend Go**: Motor de cálculo y tracking en PostgreSQL
- **Mock Services**: Para desarrollo frontend independiente

### ❌ Lo que NO incluye
- Integración con plataformas externas (Steam, etc.)
- Logros cooperativos avanzados (Fase 5)
- Achievements cross-device sync (futuro)
- Sistema de intercambio de logros

## 🗄️ BACKEND: DATABASE SCHEMA

### Achievements Master Table
```sql
CREATE TABLE achievements (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    key VARCHAR(100) UNIQUE NOT NULL, -- 'first_win', 'win_streak_5', etc.
    name VARCHAR(200) NOT NULL,
    description TEXT NOT NULL,
    category VARCHAR(50) NOT NULL, -- 'progress', 'social', 'skill', 'time', 'special'
    tier VARCHAR(20) NOT NULL DEFAULT 'bronze', -- 'bronze', 'silver', 'gold', 'platinum', 'legendary'
    
    -- Unlock conditions (JSONB for flexibility)
    unlock_conditions JSONB NOT NULL,
    -- Example: {"type": "games_won", "value": 10, "game_mode": "any"}
    
    -- Rewards
    points_reward INTEGER DEFAULT 0,
    badge_icon VARCHAR(200),
    title_unlock VARCHAR(100), -- Special title for profile
    
    -- Display properties
    is_hidden BOOLEAN DEFAULT FALSE, -- Hidden until unlocked
    is_progressive BOOLEAN DEFAULT FALSE, -- Has multiple tiers
    progression_steps JSONB, -- For progressive achievements
    
    -- Metadata
    rarity DECIMAL(5,2) DEFAULT 100.00, -- Percentage of users who have it
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    is_active BOOLEAN DEFAULT TRUE
);

CREATE INDEX idx_achievements_category ON achievements(category);
CREATE INDEX idx_achievements_tier ON achievements(tier);
CREATE INDEX idx_achievements_key ON achievements(key);
CREATE INDEX idx_achievements_active ON achievements(is_active);
```

### User Achievements Table
```sql
CREATE TABLE user_achievements (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    achievement_id UUID NOT NULL REFERENCES achievements(id) ON DELETE CASCADE,
    
    -- Progress tracking
    current_progress INTEGER DEFAULT 0,
    max_progress INTEGER NOT NULL,
    is_unlocked BOOLEAN DEFAULT FALSE,
    unlocked_at TIMESTAMP,
    
    -- Unlock context
    unlock_game_id UUID REFERENCES games(id), -- Game that triggered unlock
    unlock_context JSONB, -- Additional context data
    
    -- Progression for multi-tier achievements
    current_tier INTEGER DEFAULT 1,
    max_tier INTEGER DEFAULT 1,
    
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    
    -- Prevent duplicate user-achievement pairs
    UNIQUE(user_id, achievement_id)
);

CREATE INDEX idx_user_achievements_user_id ON user_achievements(user_id);
CREATE INDEX idx_user_achievements_unlocked ON user_achievements(user_id, is_unlocked);
CREATE INDEX idx_user_achievements_progress ON user_achievements(user_id, current_progress);
CREATE INDEX idx_user_achievements_unlocked_at ON user_achievements(unlocked_at);
```

### Progress Log Table (for analytics)
```sql
CREATE TABLE achievement_progress_log (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    achievement_id UUID NOT NULL REFERENCES achievements(id) ON DELETE CASCADE,
    
    -- Progress tracking
    old_progress INTEGER,
    new_progress INTEGER,
    progress_delta INTEGER,
    
    -- Context
    trigger_event VARCHAR(100), -- 'game_won', 'friend_added', etc.
    trigger_data JSONB,
    game_id UUID REFERENCES games(id),
    
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_progress_log_user_id ON achievement_progress_log(user_id);
CREATE INDEX idx_progress_log_achievement ON achievement_progress_log(achievement_id);
CREATE INDEX idx_progress_log_created_at ON achievement_progress_log(created_at);
```

## 📱 FRONTEND: REACT HOOKS

### useAchievements Hook
```javascript
// hooks/useAchievements.js
import { useState, useEffect, useCallback } from 'react';
import { useAuth } from './useAuth';
import { achievementsAPI } from '../services/achievementsAPI';
import { mockAchievementsService } from '../services/mockAchievementsService';

export const useAchievements = () => {
  const { isAuthenticated, user } = useAuth();
  const [achievements, setAchievements] = useState([]);
  const [userProgress, setUserProgress] = useState({});
  const [recentUnlocks, setRecentUnlocks] = useState([]);
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState(null);
  
  // Usar mock o API real según configuración
  const api = process.env.REACT_APP_USE_MOCK_ACHIEVEMENTS === 'true' 
    ? mockAchievementsService 
    : achievementsAPI;
  
  const loadAchievements = useCallback(async () => {
    if (!isAuthenticated) return;
    
    try {
      setIsLoading(true);
      const response = await api.getAchievements();
      setAchievements(response.achievements);
      
      // Process user progress
      const progressMap = {};
      response.achievements.forEach(achievement => {
        if (achievement.user_progress) {
          progressMap[achievement.key] = achievement.user_progress;
        }
      });
      setUserProgress(progressMap);
      
    } catch (err) {
      setError(err.message);
    } finally {
      setIsLoading(false);
    }
  }, [isAuthenticated, api]);
  
  const checkAchievementProgress = useCallback(async (eventType, eventData) => {
    if (!isAuthenticated) return [];
    
    try {
      const response = await api.checkProgress(eventType, eventData);
      
      if (response.unlocked_achievements?.length > 0) {
        setRecentUnlocks(prev => [
          ...response.unlocked_achievements,
          ...prev.slice(0, 4) // Keep only 5 most recent
        ]);
        
        // Update user progress for unlocked achievements
        const updatedProgress = { ...userProgress };
        response.unlocked_achievements.forEach(unlock => {
          updatedProgress[unlock.achievement.key] = {
            current_progress: unlock.achievement.max_progress || 1,
            max_progress: unlock.achievement.max_progress || 1,
            is_unlocked: true,
            unlocked_at: unlock.unlocked_at,
            percentage: 100
          };
        });
        setUserProgress(updatedProgress);
      }
      
      // Update progress for achievements that had progress updates
      if (response.progress_updates?.length > 0) {
        const updatedProgress = { ...userProgress };
        response.progress_updates.forEach(update => {
          if (updatedProgress[update.achievement_key]) {
            updatedProgress[update.achievement_key] = {
              ...updatedProgress[update.achievement_key],
              current_progress: update.new_progress,
              percentage: (update.new_progress / update.max_progress) * 100
            };
          }
        });
        setUserProgress(updatedProgress);
      }
      
      return response.unlocked_achievements || [];
      
    } catch (err) {
      console.error('Error checking achievement progress:', err);
      return [];
    }
  }, [isAuthenticated, api, userProgress]);
  
  const dismissRecentUnlock = useCallback((achievementKey) => {
    setRecentUnlocks(prev => 
      prev.filter(unlock => unlock.achievement.key !== achievementKey)
    );
  }, []);
  
  const getAchievementsByCategory = useCallback((category) => {
    return achievements.filter(achievement => achievement.category === category);
  }, [achievements]);
  
  const getUnlockedAchievements = useCallback(() => {
    return achievements.filter(achievement => 
      userProgress[achievement.key]?.is_unlocked
    );
  }, [achievements, userProgress]);
  
  const getProgressAchievements = useCallback(() => {
    return achievements.filter(achievement => {
      const progress = userProgress[achievement.key];
      return progress && !progress.is_unlocked && progress.current_progress > 0;
    });
  }, [achievements, userProgress]);
  
  useEffect(() => {
    loadAchievements();
  }, [loadAchievements]);
  
  const stats = useMemo(() => {
    const unlocked = getUnlockedAchievements();
    const totalPoints = unlocked.reduce((sum, achievement) => 
      sum + (achievement.points_reward || 0), 0
    );
    
    return {
      totalAchievements: achievements.length,
      unlockedCount: unlocked.length,
      completionPercentage: achievements.length > 0 
        ? (unlocked.length / achievements.length) * 100 
        : 0,
      totalPoints,
      inProgressCount: getProgressAchievements().length
    };
  }, [achievements, getUnlockedAchievements, getProgressAchievements]);
  
  return {
    // Estado
    achievements,
    userProgress,
    recentUnlocks,
    isLoading,
    error,
    stats,
    
    // Acciones
    checkAchievementProgress,
    dismissRecentUnlock,
    refreshAchievements: loadAchievements,
    
    // Utilidades
    getAchievementsByCategory,
    getUnlockedAchievements,
    getProgressAchievements,
    hasRecentUnlocks: recentUnlocks.length > 0
  };
};
```

```javascript
// hooks/useAchievementNotifications.js
import { useState, useCallback, useEffect } from 'react';
import { useAchievements } from './useAchievements';

export const useAchievementNotifications = () => {
  const { recentUnlocks, dismissRecentUnlock } = useAchievements();
  const [displayQueue, setDisplayQueue] = useState([]);
  const [currentNotification, setCurrentNotification] = useState(null);
  const [isShowingNotification, setIsShowingNotification] = useState(false);
  
  // Agregar nuevos unlocks a la cola de display
  useEffect(() => {
    const newUnlocks = recentUnlocks.filter(unlock => 
      !displayQueue.some(queued => queued.achievement.key === unlock.achievement.key) &&
      (!currentNotification || currentNotification.achievement.key !== unlock.achievement.key)
    );
    
    if (newUnlocks.length > 0) {
      setDisplayQueue(prev => [...prev, ...newUnlocks]);
    }
  }, [recentUnlocks, displayQueue, currentNotification]);
  
  // Mostrar siguiente notificación en la cola
  useEffect(() => {
    if (!isShowingNotification && displayQueue.length > 0) {
      const nextNotification = displayQueue[0];
      setCurrentNotification(nextNotification);
      setIsShowingNotification(true);
      setDisplayQueue(prev => prev.slice(1));
      
      // Auto-dismiss después de 5 segundos
      setTimeout(() => {
        dismissNotification();
      }, 5000);
    }
  }, [isShowingNotification, displayQueue]);
  
  const dismissNotification = useCallback(() => {
    if (currentNotification) {
      dismissRecentUnlock(currentNotification.achievement.key);
      setCurrentNotification(null);
      setIsShowingNotification(false);
    }
  }, [currentNotification, dismissRecentUnlock]);
  
  const skipToNext = useCallback(() => {
    dismissNotification();
    // La siguiente notificación se mostrará automáticamente por el useEffect
  }, [dismissNotification]);
  
  return {
    currentNotification,
    isShowingNotification,
    queueLength: displayQueue.length,
    dismissNotification,
    skipToNext,
    hasMore: displayQueue.length > 0
  };
};
```
