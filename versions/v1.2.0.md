# Version 1.2.0
**Fecha:** 21 de Diciembre 2025

## Mejoras de UX

### Verificacion de Username
- Arreglado el bug donde la verificacion de disponibilidad de username quedaba en "Verificando..." infinitamente
- Agregada logica de cancelacion para evitar race conditions
- El sistema ahora detecta si el username es el mismo que el actual y no hace verificacion innecesaria
- Mejor manejo de estados de loading

### Tab Bar en iOS
- Arreglado el bug donde el tab bar no volvia a su posicion original despues de cerrar el teclado en iOS
- Implementado uso de `visualViewport` API para mejor deteccion del teclado
- Agregados listeners para `focusin` y `focusout` en inputs
- El tab bar ahora se oculta suavemente cuando el teclado esta abierto
- Forzado scroll to top cuando el teclado se cierra para resetear el viewport

### Busqueda de Amigos
- Arreglada la busqueda que no devolvia resultados
- La busqueda ahora funciona por nombre O username (antes solo buscaba por username)
- Agregado fallback para obtener `currentUser` si no esta seteado
- Mejorada la UI del buscador:
  - Icono de lupa en el input
  - Hints de ayuda ("Escribi al menos 2 caracteres...")
  - Spinner animado mientras busca
  - Tabla de resultados con scroll interno
  - Muestra usuarios con y sin username correctamente
  - Mejor feedback cuando no hay resultados

## Archivos Modificados

### `src/components/ProfileScreen.jsx`
- Mejorado el useEffect de verificacion de username con flag `isCancelled`
- Nueva UI para busqueda de amigos con tabla estilizada
- Soporte para usuarios sin username en los resultados

### `src/hooks/useIOSViewport.js`
- Agregado estado `isKeyboardOpen`
- Implementado `visualViewport` API
- Listeners para focus/blur en inputs
- Logica de reset forzado cuando el teclado se cierra

### `src/components/IOSContainer.jsx`
- `IOSTabBar` ahora usa `isKeyboardOpen` para ocultarse
- Transicion suave con `transform: translateY(100%)`
- Effect para forzar scroll cuando el teclado se cierra

### `src/services/authService.js`
- `searchUsers()` ahora busca por `display_name` OR `name`
- Agregado fallback para obtener `currentUser`
- Agregados logs de debug para troubleshooting
